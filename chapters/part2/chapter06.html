Chương 6: Tự Xây Dựng HTTP Server với NodeJS Thuần

Trước khi dùng Express, hãy hiểu những gì xảy ra bên dưới. Chương này xây dựng HTTP server từ module http thuần — không framework, không package ngoài — giúp bạn thực sự hiểu cách một web framework hoạt động như thế nào.

🎯 Sau chương này bạn sẽ
  • Tạo HTTP server bằng module http thuần của NodeJS
  • Đọc method, URL, headers và body từ request
  • Gửi response với status code và headers đúng chuẩn HTTP
  • Implement routing thủ công không cần framework
  • Parse request body dạng JSON và form-urlencoded
  • Phục vụ static files từ filesystem
  • Hiểu tại sao cần framework như Express thay vì dùng thuần

6.1 Module http — Tạo Server Đầu Tiên

Module http là một trong những core modules quan trọng nhất của NodeJS. Nó cho phép bạn tạo HTTP server mà không cần cài bất kỳ package nào từ npm.

Hàm chính là http.createServer(requestListener) — nhận một callback được gọi mỗi khi có request đến. Callback này nhận 2 tham số:

  • req (IncomingMessage) — đối tượng đại diện cho request đến, là một Readable Stream
  • res (ServerResponse) — đối tượng để gửi response về, là một Writable Stream
JavaScriptserver-basic.js
// Không cần npm install gì cả — http là built-in module
const http = require('http');

// Tạo server — callback gọi mỗi khi có HTTP request đến
const server = http.createServer((req, res) => {
  // Gửi response với status 200 và content type text/plain
  res.writeHead(200, {
    'Content-Type': 'text/plain; charset=utf-8'
  });
  res.end('Xin chào từ NodeJS HTTP Server!');
});

// Lắng nghe cổng 3000
server.listen(3000, '127.0.0.1', () => {
  console.log('Server đang chạy tại http://localhost:3000');
  console.log('Nhấn Ctrl+C để dừng.');
});

// Xử lý lỗi server
server.on('error', (err) => {
  if (err.code === 'EADDRINUSE') {
    console.error('Cổng 3000 đang bị dùng bởi ứng dụng khác!');
  } else {
    console.error('Lỗi server:', err.message);
  }
  process.exit(1);
});

node server-basic.js

📌 Lưu ý về server.listen()

server.listen(port) là bất đồng bộ — callback chạy khi server đã sẵn sàng nhận kết nối. Nếu không truyền host, server sẽ lắng nghe trên tất cả interfaces (0.0.0.0). Truyền '127.0.0.1' nếu chỉ muốn truy cập từ máy local.

6.2 Request Object — Đọc Dữ Liệu Đến

Đối tượng req (kiểu http.IncomingMessage) chứa tất cả thông tin về request đến. Đây là một Readable Stream nên bạn cần đọc dữ liệu theo cách stream.

Các thuộc tính cơ bản của req

JavaScriptread-request.js
const http = require('http');

const server = http.createServer((req, res) => {
  // ── Method: GET, POST, PUT, DELETE, PATCH...
  console.log('Method:', req.method);        // 'GET'

  // ── URL đầy đủ bao gồm query string
  console.log('URL:', req.url);              // '/users?page=2&limit=10'

  // ── HTTP version
  console.log('HTTP version:', req.httpVersion); // '1.1'

  // ── Tất cả request headers (lowercase keys)
  console.log('Headers:', req.headers);
  console.log('Content-Type:', req.headers['content-type']);
  console.log('User-Agent:', req.headers['user-agent']);
  console.log('Authorization:', req.headers['authorization']);

  // ── Remote IP
  console.log('Client IP:', req.socket.remoteAddress);

  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Đã nhận request');
});

server.listen(3000);

Parse URL và Query String

req.url trả về chuỗi đầy đủ như /users?page=2&name=nguyen. Để làm việc thuận tiện, dùng class URL built-in: 

JavaScriptparse-url.js
const http = require('http');

const server = http.createServer((req, res) => {
  // Cách hiện đại: dùng class URL (Node 10+)
  // Cần base URL để parse tương đối
  const url = new URL(req.url, `http://${req.headers.host}`);

  console.log('Pathname:', url.pathname);     // '/users'
  console.log('Search:', url.search);         // '?page=2&name=nguyen'

  // Đọc query params dễ dàng
  const page = url.searchParams.get('page');         // '2'
  const name = url.searchParams.get('name');         // 'nguyen'
  const limit = url.searchParams.get('limit') ?? '10'; // '10' (default)

  // searchParams tự động decode URL encoding
  // ?q=xin+ch%C3%A0o → 'xin chào'

  // Cách cũ (vẫn hoạt động):
  // const qs = req.url.split('?')[1] || '';
  // const params = new URLSearchParams(qs);

  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ pathname: url.pathname, page, name, limit }));
});

server.listen(3000);

Đọc Request Body

Vì req là Readable Stream, body không có sẵn ngay lập tức. Bạn phải "tích lũy" dữ liệu từ các data events và đợi end event: 

JavaScriptread-body.js
const http = require('http');

/**
 * Đọc toàn bộ body của request, trả về Promise
 * @param {http.IncomingMessage} req
 * @param {number} [maxBytes=1048576] - giới hạn 1MB
 */
function readBody(req, maxBytes = 1_048_576) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let totalSize = 0;

    req.on('data', (chunk) => {
      totalSize += chunk.length;

      // Bảo vệ: từ chối body quá lớn
      if (totalSize > maxBytes) {
        req.destroy(); // Hủy kết nối
        reject(new Error('Request body quá lớn (tối đa 1MB)'));
        return;
      }
      chunks.push(chunk);
    });

    req.on('end', () => {
      // Ghép các Buffer thành một và chuyển sang string
      resolve(Buffer.concat(chunks).toString('utf8'));
    });

    req.on('error', (err) => {
      reject(err);
    });
  });
}
