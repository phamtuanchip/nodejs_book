Chương 3: NodeJS là gì? Cài đặt Môi Trường Lập Trình

Bây giờ bạn đã hiểu web hoạt động như thế nào, đã đến lúc gặp gỡ công cụ chính. Chương này giải thích NodeJS là gì, tại sao nó đặc biệt, và giúp bạn cài đặt đầy đủ môi trường để bắt đầu code.

  • Cài đặt NodeJS, npm và VS Code
  • Chạy được chương trình NodeJS đầu tiên
  • Hiểu cơ bản về Event Loop — thứ làm NodeJS khác biệt
  • Biết cách dùng npm để quản lý packages

3.1 NodeJS là gì?

Trước năm 2009, JavaScript chỉ sống trong trình duyệt. Bạn không thể dùng JS để đọc file, truy cập database, hay xây dựng server.

Năm 2009, Ryan Dahl tạo ra NodeJS — một môi trường chạy JavaScript bên ngoài trình duyệt, sử dụng V8 engine (engine JS của Chrome) cùng với thư viện libuv để xử lý I/O bất đồng bộ.

NodeJS không phải là ngôn ngữ mới hay framework — nó là runtime environment (môi trường chạy) cho JavaScript.

Tại sao NodeJS phổ biến?

  • Một ngôn ngữ cho cả frontend lẫn backend — dùng JS ở khắp nơi
  • Non-blocking I/O — xử lý hàng nghìn kết nối đồng thời hiệu quả
  • Hệ sinh thái npm khổng lồ — hơn 2 triệu packages
  • Cộng đồng lớn — dễ tìm tài liệu, giải pháp
  • Nhanh — V8 engine tối ưu cao, libuv xử lý I/O hiệu quả

NodeJS phù hợp cho gì?

Phù hợp ✅ Không phù hợp ❌
REST API, GraphQL API CPU-intensive tasks (ML, video encoding)
Real-time apps (chat, gaming) Tính toán nặng liên tục
Microservices Heavy computation without worker threads
Streaming (video, audio)
CLI tools, build tools

3.2 Event Loop — Trái Tim của NodeJS

Điều làm NodeJS đặc biệt là non-blocking, event-driven architecture. Hãy so sánh với cách server truyền thống hoạt động:

NodeJS dùng Event Loop để quản lý điều này. Khi có I/O (đọc file, query DB, HTTP request), NodeJS không đứng chờ — nó đăng ký callback và tiếp tục xử lý việc khác. Khi I/O xong, callback được gọi. 

        

          JavaScript
          event-loop-demo.js
          
        

        const fs = require('fs');

console.log('1 - Bắt đầu đọc file...');

// Đọc file bất đồng bộ - không block
fs.readFile('data.txt', 'utf8', (err, content) => {
  // Callback này chạy SAU khi file đọc xong
  console.log('3 - File đã đọc xong:', content.length, 'ký tự');
});

// Dòng này chạy NGAY LẬP TỨC, không chờ file
console.log('2 - Dòng này chạy trong khi file đang được đọc!');

// Kết quả:
// 1 - Bắt đầu đọc file...
// 2 - Dòng này chạy trong khi file đang được đọc!
// 3 - File đã đọc xong: 1234 ký tự
📌 Ghi nhớ
NodeJS là single-threaded nhưng non-blocking. Một thread, nhưng không bao giờ "ngồi chờ" I/O — nó luôn làm việc khác trong lúc chờ. Đây là sức mạnh của Event Loop.

3.5 Module System trong NodeJS

NodeJS sử dụng hệ thống module để chia code thành các file riêng biệt.

CommonJS (require) — Cách truyền thống

        

          JavaScript
          math.js
          
        

        // Định nghĩa và export
function add(a, b) { return a + b; }
function subtract(a, b) { return a - b; }
const PI = 3.14159;

module.exports = { add, subtract, PI };

// Hoặc export từng cái:
// module.exports.add = add;
      
        

          JavaScript
          main.js
          
        

        // Import module tự viết
const math = require('./math');           // ./ = cùng thư mục
console.log(math.add(5, 3));              // 8
console.log(math.PI);                     // 3.14159

// Destructuring
const { add, PI } = require('./math');
console.log(add(10, 5));                  // 15

// Import module built-in (không cần ./)
const fs = require('fs');
const path = require('path');

// Import package từ npm (không cần ./)
const express = require('express');

ES Modules (import/export) — Cách hiện đại

        

          JavaScript
          math.mjs (hoặc thêm "type":"module" vào package.json)
          
        

        // ES Module export
export function add(a, b) { return a + b; }
export const PI = 3.14159;
export default function multiply(a, b) { return a * b; }

// Import
import multiply, { add, PI } from './math.mjs';
console.log(add(2, 3));      // 5
console.log(multiply(4, 5)); // 20
💡 Nên dùng cái nào?
Hiện tại hầu hết tutorial và codebase NodeJS dùng CommonJS (require). ES Modules đang dần phổ biến hơn, đặc biệt với Typescript. Trong sách này chúng ta sẽ dùng CommonJS ở phần đầu, chuyển sang ES Modules ở phần sau.

3.6 npm — Node Package Manager

npm là gì?

npm là kho thư viện lớn nhất thế giới với hơn 2 triệu packages. Nó đi kèm với NodeJS và dùng để cài, quản lý các thư viện bên thứ ba. 

        

          Shell
          Các lệnh npm hay dùng

npm install express
npm install mongoose jsonwebtoken  # Cài nhiều cùng lúc

# Cài package chỉ cho development (không deploy lên production)
npm install --save-dev nodemon jest

# Cài package globally (dùng như CLI tool)

# Xóa package

# Xem danh sách package đã cài
npm list

# Cập nhật packages
npm update

# Kiểm tra lỗi bảo mật
npm audit
npm audit fix

3.8 Script tính toán đầu tiên

Hãy viết một script thực tế hơn Hello World:

        

          JavaScript
          calculator.js
          
        

        // Nhận arguments từ command line
// Chạy: node calculator.js 10 + 5
const args = process.argv.slice(2); // Bỏ "node" và "calculator.js"

if (args.length !== 3) {
  console.error('Cách dùng: node calculator.js   ');
  console.error('Ví dụ: node calculator.js 10 + 5');
  process.exit(1); // Thoát với lỗi
}

const [num1Str, operator, num2Str] = args;
const num1 = parseFloat(num1Str);
const num2 = parseFloat(num2Str);

if (isNaN(num1) || isNaN(num2)) {
  console.error('Lỗi: Vui lòng nhập số hợp lệ');
  process.exit(1);
}

let result;
switch (operator) {
  case '+': result = num1 + num2; break;
  case '-': result = num1 - num2; break;
  case '*': result = num1 * num2; break;
  case '/':
    if (num2 === 0) {
      console.error('Lỗi: Không thể chia cho 0');
      process.exit(1);
    }
    result = num1 / num2;
    break;
  default:
    console.error(`Lỗi: Phép tính '${operator}' không được hỗ trợ`);
    process.exit(1);
}

console.log(`${num1} ${operator} ${num2} = ${result}`);
      
        

          Shell
          
        

        node calculator.js 10 + 5
# 10 + 5 = 15

node calculator.js 100 / 4
# 100 / 4 = 25

node calculator.js 7.5 "*" 3
# 7.5 * 3 = 22.5

node calculator.js 10 / 0
# Lỗi: Không thể chia cho 0
📚 Tóm tắt chương 3
  • NodeJS là runtime environment cho JavaScript bên ngoài browser, dùng V8 engine + libuv
  • Event Loop cho phép NodeJS xử lý I/O bất đồng bộ với single thread — hiệu quả cao
  • Cài NodeJS qua nvm (khuyên dùng) hoặc tải trực tiếp từ nodejs.org
  • CommonJS (require/module.exports) là module system mặc định
  • npm quản lý packages; package.json là hồ sơ project
  • nodemon giúp tự động restart server khi dev
