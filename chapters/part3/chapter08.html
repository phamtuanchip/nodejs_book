Phần 3 — Web Application với Express

Chương 8: Express.js — Framework Web Phổ Biến Nhất

Express biến một HTTP server thuần cồng kềnh thành vài dòng code gọn gàng. Chương này học cách xây dựng REST API hoàn chỉnh với Express — routing, params, body, và tổ chức code chuẩn.

🎯 Sau chương này bạn sẽ biết
  • Cài đặt và cấu hình Express app từ đầu
  • Định nghĩa routes với đầy đủ HTTP methods (GET, POST, PUT, PATCH, DELETE)
  • Đọc route params, query strings, và request body
  • Tổ chức routes gọn gàng với Express Router
  • Xây dựng REST API hoàn chỉnh với CRUD operations

8.1 Tại sao cần Express?

Ở chương 6, bạn đã viết HTTP server thuần bằng module http của Node. Nó hoạt động, nhưng khi ứng dụng lớn hơn — nhiều routes, nhiều methods, parse body, validate data — code sẽ nhanh chóng trở thành một mớ if/else lộn xộn.

Hãy xem cùng một tính năng "Lấy danh sách sản phẩm" được viết theo hai cách:

Express không phải là một framework "nặng" như Django hay Rails. Nó là một thin layer (lớp mỏng) nằm trên module http của Node, cung cấp:

  • Routing — khớp URL với handler function một cách thanh lịch
  • Middleware — pipeline xử lý request/response
  • Request/Response helpers — req.params, req.body, res.json()...
  • Extensibility — hàng nghìn middleware từ npm
📌 Express là số 1
Express là framework Node.js được tải xuống nhiều nhất trên npm — trên 30 triệu lần/tuần. Hầu hết các framework khác (NestJS, Fastify, Koa) đều lấy cảm hứng hoặc build on top của nó. Hiểu Express = hiểu nền tảng của hầu hết Node.js web development.

Đây là cùng một tính năng viết bằng hai cách — quan sát sự khác biệt:

JavaScriptserver-raw.js — HTTP thuần
const http = require('http');
const url = require('url');

const products = [
  { id: 1, name: 'Laptop', price: 25000000 },
  { id: 2, name: 'Mouse', price: 350000 },
];

const server = http.createServer((req, res) => {
  const parsed = url.parse(req.url, true);
  const pathname = parsed.pathname;
  const method = req.method;

  // Phải tự xử lý từng route
  if (pathname === '/products' && method === 'GET') {
    res.writeHead(200, {
      'Content-Type': 'application/json',
      'X-Powered-By': 'Node.js'
    });
    res.end(JSON.stringify({ success: true, data: products }));

  } else if (pathname.match(/^\/products\/\d+$/) && method === 'GET') {
    const id = parseInt(pathname.split('/')[2]);
    const product = products.find(p => p.id === id);
    if (product) {
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ success: true, data: product }));
    } else {
      res.writeHead(404, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ success: false, error: 'Not found' }));
    }

  } else {
    res.writeHead(404, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ error: 'Route not found' }));
  }
});

server.listen(3000);
JavaScriptserver-express.js — Với Express
const express = require('express');
const app = express();

const products = [
  { id: 1, name: 'Laptop', price: 25000000 },
  { id: 2, name: 'Mouse', price: 350000 },
];

// Express tự handle routing, parsing, và response helpers
app.get('/products', (req, res) => {
  res.json({ success: true, data: products });
});

app.get('/products/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const product = products.find(p => p.id === id);

  if (!product) {
    return res.status(404).json({ success: false, error: 'Not found' });
  }

  res.json({ success: true, data: product });
});

app.listen(3000, () => console.log('Server chạy tại http://localhost:3000'));

8.3 Routing — Xử Lý Các HTTP Methods

Express cung cấp một method tương ứng với mỗi HTTP method. Quy tắc CRUD rất rõ ràng:

  • app.get(path, handler) — Đọc dữ liệu (Read)
  • app.post(path, handler) — Tạo mới (Create)
  • app.put(path, handler) — Cập nhật toàn bộ (Replace)
  • app.patch(path, handler) — Cập nhật một phần (Partial update)
  • app.delete(path, handler) — Xóa (Delete)
  • app.all(path, handler) — Khớp với mọi HTTP method

Ví dụ đầy đủ CRUD cho resource "products" dùng in-memory array (chưa dùng database): 

JavaScriptapp.js — CRUD đầy đủ
const express = require('express');
const app = express();

// Middleware quan trọng: parse JSON request body
app.use(express.json());

// "Database" tạm thời trong bộ nhớ
let products = [
  { id: 1, name: 'Laptop Dell XPS 13', price: 28000000, category: 'electronics', stock: 15 },
  { id: 2, name: 'Chuột Logitech MX Master', price: 1800000, category: 'electronics', stock: 50 },
  { id: 3, name: 'Bàn phím Keychron K2', price: 2200000, category: 'electronics', stock: 30 },
];
let nextId = 4; // Auto-increment ID

// ── GET /products ── Lấy danh sách (có thể filter)
app.get('/products', (req, res) => {
  let result = [...products];

  // Filter theo category: GET /products?category=electronics
  if (req.query.category) {
    result = result.filter(p => p.category === req.query.category);
  }

  // Filter theo giá tối đa: GET /products?maxPrice=5000000
  if (req.query.maxPrice) {
    result = result.filter(p => p.price <= parseInt(req.query.maxPrice));
  }

  res.json({
    success: true,
    total: result.length,
    data: result
  });
});

// ── GET /products/:id ── Lấy 1 sản phẩm
app.get('/products/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const product = products.find(p => p.id === id);

  if (!product) {
    return res.status(404).json({
      success: false,
      error: `Không tìm thấy sản phẩm với id=${id}`
    });
  }

  res.json({ success: true, data: product });
});

// ── POST /products ── Tạo sản phẩm mới
app.post('/products', (req, res) => {
  const { name, price, category, stock } = req.body;

  // Validate required fields
  if (!name || price === undefined || !category) {
    return res.status(400).json({
      success: false,
      error: 'Thiếu thông tin bắt buộc: name, price, category'
    });
  }

  const newProduct = {
    id: nextId++,
    name,
    price: Number(price),
    category,
    stock: stock ?? 0,
    createdAt: new Date().toISOString()
  };

  products.push(newProduct);

  // 201 Created
  res.status(201).json({
    success: true,
    message: 'Tạo sản phẩm thành công',
    data: newProduct
  });
});

// ── PUT /products/:id ── Cập nhật toàn bộ (replace)
app.put('/products/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const index = products.findIndex(p => p.id === id);

  if (index === -1) {
    return res.status(404).json({ success: false, error: 'Không tìm thấy sản phẩm' });
  }

  const { name, price, category, stock } = req.body;
  if (!name || price === undefined || !category) {
    return res.status(400).json({ success: false, error: 'PUT yêu cầu đầy đủ tất cả fields' });
  }

  products[index] = { id, name, price: Number(price), category, stock: stock ?? 0 };
  res.json({ success: true, data: products[index] });
});

// ── PATCH /products/:id ── Cập nhật một phần
app.patch('/products/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const index = products.findIndex(p => p.id === id);

  if (index === -1) {
    return res.status(404).json({ success: false, error: 'Không tìm thấy sản phẩm' });
  }

  // Merge dữ liệu cũ với dữ liệu mới
  products[index] = { ...products[index], ...req.body };
  res.json({ success: true, data: products[index] });
});

// ── DELETE /products/:id ── Xóa sản phẩm
app.delete('/products/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const index = products.findIndex(p => p.id === id);

  if (index === -1) {
    return res.status(404).json({ success: false, error: 'Không tìm thấy sản phẩm' });
  }

  const deleted = products.splice(index, 1)[0];
  res.json({
    success: true,
    message: `Đã xóa sản phẩm "${deleted.name}"`,
    data: deleted
  });
});

app.listen(3000, () => console.log('Server tại http://localhost:3000'));
💡 Multiple callbacks trên 1 route
Express cho phép bạn đặt nhiều handler function cho 1 route. Mỗi function phải gọi next() để chuyển sang function tiếp theo — đây chính là cơ chế middleware (Chương 9):

app.get('/products', checkAuth, logRequest, (req, res) => { ... })

8.4 Request Object — Đọc Dữ Liệu Từ Client

Object req (request) chứa tất cả thông tin mà client gửi lên. Đây là những thuộc tính quan trọng nhất: 

JavaScriptrequest-info.js — Debug tool
// Route debug: hiển thị mọi thứ trong request
// Truy cập: GET /debug/info?page=2&limit=10
app.get('/debug/info', (req, res) => {
  res.json({
    // ── Route Parameters ──────────────────────
    // /users/:userId/posts/:postId → req.params
    params: req.params,

    // ── Query String ──────────────────────────
    // /debug/info?page=2&limit=10&tag=nodejs
    query: req.query,
    // req.query.page → '2' (luôn là string!)
    // Cần convert: parseInt(req.query.page)

    // ── Request Body ─────────────────────────
    // Cần middleware: app.use(express.json())
    body: req.body,

    // ── HTTP Headers ─────────────────────────
    headers: {
      contentType: req.get('Content-Type'),     // 'application/json'
      authorization: req.get('Authorization'),  // 'Bearer abc123'
      userAgent: req.get('User-Agent'),
      accept: req.get('Accept'),
    },

    // ── Request Meta ─────────────────────────
    method: req.method,       // 'GET'
    url: req.url,             // '/debug/info?page=2&limit=10'
    path: req.path,           // '/debug/info' (không có query string)
    hostname: req.hostname,   // 'localhost'
    ip: req.ip,               // '::1' hoặc '127.0.0.1'
    protocol: req.protocol,   // 'http' hoặc 'https'
    secure: req.secure,       // true nếu HTTPS

    // ── Cookies ──────────────────────────────
    // Cần middleware 'cookie-parser'
    cookies: req.cookies,
  });
});

// ── Ví dụ đọc route params ──
// Route: /users/:userId/posts/:postId
app.get('/users/:userId/posts/:postId', (req, res) => {
  const { userId, postId } = req.params;
  // req.params = { userId: '42', postId: '7' }
  // Lưu ý: params luôn là STRING, cần parseInt nếu muốn số

  res.json({
    message: `Bài viết ${postId} của user ${userId}`,
    userId: parseInt(userId),  // convert sang number
    postId: parseInt(postId),
  });
});

// ── Ví dụ đọc query string ──
// GET /search?q=nodejs&page=2&limit=10&sort=newest
app.get('/search', (req, res) => {
  const {
    q = '',           // từ khóa tìm kiếm
    page = '1',       // trang hiện tại
    limit = '10',     // số kết quả mỗi trang
    sort = 'newest'   // cách sắp xếp
  } = req.query;

  res.json({
    keyword: q,
    page: parseInt(page),
    limit: Math.min(parseInt(limit), 100), // Giới hạn tối đa 100
    sort,
    results: [] // Giả sử data ở đây
  });
});
⚠️ Params và Query luôn là String
req.params.id và req.query.page luôn trả về string, ngay cả khi client gửi số. Bạn phải tự convert: parseInt(req.params.id) hoặc Number(req.query.limit). Nếu không, so sánh như product.id === req.params.id sẽ luôn false vì 1 !== '1'.

Trong thực tế, bạn nên tạo một helper function để trả response nhất quán trên toàn bộ API: 

JavaScripthelpers/apiResponse.js
/**
 * Helper tạo response API nhất quán
 *
 * Ví dụ dùng:
 *   apiResponse(res, 200, { users }, 'Lấy danh sách thành công')
 *   apiResponse(res, 404, null, 'Không tìm thấy', false)
 */
function apiResponse(res, statusCode, data = null, message = '', success = true) {
  const response = {
    success,
    message,
    ...(data !== null && { data })
  };

  return res.status(statusCode).json(response);
}

// Shortcuts hay dùng
const ok = (res, data, message = 'Thành công') =>
  apiResponse(res, 200, data, message);

const created = (res, data, message = 'Tạo thành công') =>
  apiResponse(res, 201, data, message);

const notFound = (res, message = 'Không tìm thấy') =>
  apiResponse(res, 404, null, message, false);

const badRequest = (res, message = 'Dữ liệu không hợp lệ') =>
  apiResponse(res, 400, null, message, false);

const serverError = (res, message = 'Lỗi server nội bộ') =>
  apiResponse(res, 500, null, message, false);

module.exports = { apiResponse, ok, created, notFound, badRequest, serverError };

8.6 Express Router — Tổ Chức Code Theo Module

Khi ứng dụng lớn dần, không nên nhét tất cả routes vào một file app.js. Express cung cấp express.Router() để tách routes thành các module riêng biệt.

Cấu trúc thư mục được đề xuất:

TextCấu trúc project
my-express-app/
├── app.js              ← Entry point, mount routers
├── routes/
│   ├── products.js     ← Router cho /api/products
│   └── users.js        ← Router cho /api/users
├── package.json
└── node_modules/
JavaScriptroutes/products.js
const express = require('express');
const router = express.Router();

// "Database" in-memory
let products = [
  { id: 1, name: 'Laptop', price: 28000000 },
  { id: 2, name: 'Mouse', price: 350000 },
];
let nextId = 3;

// Lưu ý: path ở đây là RELATIVE so với mount point
// Khi mount tại '/api/products', thì:
//   router.get('/')       → GET /api/products
//   router.get('/:id')    → GET /api/products/:id

router.get('/', (req, res) => {
  res.json({ success: true, data: products });
});

router.get('/:id', (req, res) => {
  const product = products.find(p => p.id === parseInt(req.params.id));
  if (!product) return res.status(404).json({ success: false, error: 'Không tìm thấy' });
  res.json({ success: true, data: product });
});

router.post('/', (req, res) => {
  const { name, price } = req.body;
  if (!name || price === undefined) {
    return res.status(400).json({ success: false, error: 'Thiếu name hoặc price' });
  }
  const product = { id: nextId++, name, price: Number(price) };
  products.push(product);
  res.status(201).json({ success: true, data: product });
});

router.put('/:id', (req, res) => {
  const idx = products.findIndex(p => p.id === parseInt(req.params.id));
  if (idx === -1) return res.status(404).json({ success: false, error: 'Không tìm thấy' });
  products[idx] = { ...products[idx], ...req.body };
  res.json({ success: true, data: products[idx] });
});

router.delete('/:id', (req, res) => {
  const idx = products.findIndex(p => p.id === parseInt(req.params.id));
  if (idx === -1) return res.status(404).json({ success: false, error: 'Không tìm thấy' });
  const [deleted] = products.splice(idx, 1);
  res.json({ success: true, data: deleted });
});

module.exports = router;
JavaScriptroutes/users.js
const express = require('express');
const router = express.Router();

let users = [
  { id: 1, name: 'Nguyễn Văn An', email: 'an@example.com', role: 'admin' },
  { id: 2, name: 'Trần Thị Bình', email: 'binh@example.com', role: 'user' },
];

router.get('/', (req, res) => {
  // Lọc theo role: GET /api/users?role=admin
  const { role } = req.query;
  const result = role ? users.filter(u => u.role === role) : users;
  res.json({ success: true, data: result });
});

router.get('/:id', (req, res) => {
  const user = users.find(u => u.id === parseInt(req.params.id));
  if (!user) return res.status(404).json({ success: false, error: 'Không tìm thấy user' });
  res.json({ success: true, data: user });
});

router.post('/register', (req, res) => {
  const { name, email } = req.body;
  if (!name || !email) {
    return res.status(400).json({ success: false, error: 'Cần name và email' });
  }
  const exists = users.find(u => u.email === email);
  if (exists) {
    return res.status(409).json({ success: false, error: 'Email đã tồn tại' });
  }
  const user = { id: users.length + 1, name, email, role: 'user' };
  users.push(user);
  res.status(201).json({ success: true, data: user });
});

module.exports = router;

8.7 Built-in Middleware

Express đi kèm một số middleware tích hợp sẵn. Thứ tự đặt middleware RẤT QUAN TRỌNG — chúng phải được đặt TRƯỚC các routes cần dùng đến chúng: 

JavaScriptapp.js — Built-in middleware
const express = require('express');
const app = express();

// ── 1. express.json() ──────────────────────────────────────
// Parse request body khi Content-Type: application/json
// Không có middleware này, req.body sẽ là undefined với JSON request
app.use(express.json({
  limit: '10mb',     // Giới hạn kích thước body (mặc định 100kb)
  strict: true       // Chỉ chấp nhận object và array (không chấp nhận primitive)
}));

// ── 2. express.urlencoded() ────────────────────────────────
// Parse request body khi Content-Type: application/x-www-form-urlencoded
// Dùng khi submit HTML form truyền thống
app.use(express.urlencoded({
  extended: true,  // true = dùng qs library (hỗ trợ nested objects)
                   // false = dùng querystring library (đơn giản hơn)
  limit: '10mb'
}));

// ── 3. express.static() ───────────────────────────────────
// Serve static files (HTML, CSS, JS, images) từ thư mục chỉ định
// Truy cập: GET /logo.png → đọc file public/logo.png
app.use(express.static('public', {
  maxAge: '1d',      // Cache 1 ngày trên client
  etag: true,        // Bật ETag cho caching thông minh
  index: 'index.html' // File mặc định khi truy cập thư mục
}));

// Serve từ nhiều thư mục:
// app.use('/uploads', express.static('uploads'));
// app.use('/assets', express.static('assets'));

// Routes đặt SAU middleware
app.get('/api/test', (req, res) => {
  // req.body đã được parse, sẵn sàng dùng
  res.json({ received: req.body });
});

app.listen(3000);
⚠️ Thứ tự middleware quan trọng
Middleware được thực thi theo thứ tự bạn khai báo. Đặt express.json() TRƯỚC route handlers. Nếu đặt sau, req.body sẽ là undefined khi route handler chạy, vì JSON chưa được parse.

8.8 Dự án thực hành: API Blog đơn giản

Áp dụng tất cả kiến thức trong chương để xây dựng một Blog API hoàn chỉnh. API này dùng in-memory storage (chưa có database) nhưng có đầy đủ các tính năng cơ bản.

const express = require('express');
const router = express.Router();

// ── Data Store (in-memory) ──

    createdAt: '2024-02-01T14:00:00.000Z',
    updatedAt: '2024-02-01T14:00:00.000Z',
  },
];

let comments = [
  { id: 1, postId: 1, author: 'Charlie', content: 'Bài viết rất hay!', createdAt: '2024-01-16T09:00:00.000Z' },
  { id: 2, postId: 1, author: 'Diana', content: 'Cảm ơn, rất hữu ích.', createdAt: '2024-01-17T11:00:00.000Z' },
  { id: 3, postId: 2, author: 'Eve', content: 'Tôi có câu hỏi về...', createdAt: '2024-01-21T15:00:00.000Z' },
];

let nextPostId = 4;
let nextCommentId = 4;

// ── GET /api/posts ── Lấy danh sách, hỗ trợ filter
router.get('/', (req, res) => {
  const { author, tag, page = '1', limit = '10' } = req.query;

  let result = [...posts];

  // Filter theo author
  if (author) {
    result = result.filter(p =>
      p.author.toLowerCase() === author.toLowerCase()
    );
  }

  // Filter theo tag
  if (tag) {
    result = result.filter(p => p.tags.includes(tag));
  }

  // Sắp xếp mới nhất trước
  result.sort((a, b) => new Date(b.createdAt) - new Date(a.createdAt));

  // Pagination
  const pageNum = Math.max(1, parseInt(page));
  const limitNum = Math.min(50, Math.max(1, parseInt(limit)));
  const startIdx = (pageNum - 1) * limitNum;
  const paginatedResult = result.slice(startIdx, startIdx + limitNum);

  res.json({
    success: true,
    data: paginatedResult,
    pagination: {
      total: result.length,
      page: pageNum,
      limit: limitNum,
      totalPages: Math.ceil(result.length / limitNum),
      hasNext: startIdx + limitNum < result.length,
      hasPrev: pageNum > 1,
    }
  });
});

// ── GET /api/posts/search ── Tìm kiếm theo title hoặc content
// Phải đặt TRƯỚC route /:id vì 'search' sẽ bị hiểu là :id
router.get('/search', (req, res) => {
  const { q } = req.query;
  if (!q || q.trim() === '') {
    return res.status(400).json({ success: false, error: 'Cần cung cấp từ khóa tìm kiếm ?q=' });
  }

  const keyword = q.toLowerCase().trim();
  const results = posts.filter(p =>
    p.title.toLowerCase().includes(keyword) ||
    p.content.toLowerCase().includes(keyword) ||
    p.tags.some(t => t.includes(keyword))
  );

  res.json({ success: true, total: results.length, keyword: q, data: results });
});

// ── GET /api/posts/stats ── Thống kê
router.get('/stats', (req, res) => {
  const postWithMostComments = posts.reduce((best, post) => {
    const count = comments.filter(c => c.postId === post.id).length;
    const bestCount = comments.filter(c => c.postId === best.id).length;
    return count > bestCount ? post : best;
  }, posts[0]);

  const authorStats = posts.reduce((acc, post) => {
    acc[post.author] = (acc[post.author] || 0) + 1;
    return acc;
  }, {});

  res.json({
    success: true,
    data: {
      totalPosts: posts.length,
      totalComments: comments.length,
      postWithMostComments: postWithMostComments
        ? { ...postWithMostComments, commentCount: comments.filter(c => c.postId === postWithMostComments.id).length }
        : null,
      postsByAuthor: authorStats,
      allTags: [...new Set(posts.flatMap(p => p.tags))].sort(),
    }
  });
});

// ── GET /api/posts/:id ── Chi tiết bài viết
router.get('/:id', (req, res) => {
  const id = parseInt(req.params.id);
  if (isNaN(id)) {
    return res.status(400).json({ success: false, error: 'ID phải là số' });
  }

  const post = posts.find(p => p.id === id);
  if (!post) {
    return res.status(404).json({ success: false, error: `Không tìm thấy bài viết id=${id}` });
  }

  const postComments = comments.filter(c => c.postId === id);

  res.json({
    success: true,
    data: {
      ...post,
      commentCount: postComments.length
    }
  });
});

// ── POST /api/posts ── Tạo bài viết mới
router.post('/', (req, res) => {
  const { title, content, author, tags = [] } = req.body;

  // Validate
  const errors = [];
  if (!title || title.trim() === '') errors.push('title là bắt buộc');
  if (!content || content.trim() === '') errors.push('content là bắt buộc');
  if (!author || author.trim() === '') errors.push('author là bắt buộc');
  if (!Array.isArray(tags)) errors.push('tags phải là array');

  if (errors.length > 0) {
    return res.status(400).json({ success: false, errors });
  }

  const now = new Date().toISOString();
  const newPost = {
    id: nextPostId++,
    title: title.trim(),
    content: content.trim(),
    author: author.trim(),
    tags: tags.map(t => String(t).toLowerCase().trim()),
    createdAt: now,
    updatedAt: now,
  };

  posts.push(newPost);
  res.status(201).json({ success: true, data: newPost });
});

// ── PUT /api/posts/:id ── Cập nhật toàn bộ bài viết
router.put('/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const idx = posts.findIndex(p => p.id === id);
  if (idx === -1) return res.status(404).json({ success: false, error: 'Không tìm thấy' });

  const { title, content, author, tags } = req.body;
  if (!title || !content || !author) {
    return res.status(400).json({ success: false, error: 'Cần đầy đủ title, content, author' });
  }

  posts[idx] = {
    ...posts[idx],
    title: title.trim(),
    content: content.trim(),
    author: author.trim(),
    tags: Array.isArray(tags) ? tags : posts[idx].tags,
    updatedAt: new Date().toISOString(),
  };

  res.json({ success: true, data: posts[idx] });
});

// ── DELETE /api/posts/:id ── Xóa bài viết
router.delete('/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const idx = posts.findIndex(p => p.id === id);
  if (idx === -1) return res.status(404).json({ success: false, error: 'Không tìm thấy' });

  const [deleted] = posts.splice(idx, 1);
  // Xóa cả comments liên quan
  const deletedComments = comments.filter(c => c.postId === id).length;
  comments = comments.filter(c => c.postId !== id);

  res.json({
    success: true,
    message: `Đã xóa bài viết và ${deletedComments} comments liên quan`,
    data: deleted
  });
});

// ── GET /api/posts/:id/comments ── Lấy comments của bài viết
router.get('/:id/comments', (req, res) => {
  const id = parseInt(req.params.id);
  const post = posts.find(p => p.id === id);
  if (!post) return res.status(404).json({ success: false, error: 'Bài viết không tồn tại' });

  const postComments = comments.filter(c => c.postId === id);
  res.json({ success: true, total: postComments.length, data: postComments });
});

// ── POST /api/posts/:id/comments ── Thêm comment
router.post('/:id/comments', (req, res) => {
  const id = parseInt(req.params.id);
  const post = posts.find(p => p.id === id);
  if (!post) return res.status(404).json({ success: false, error: 'Bài viết không tồn tại' });

  const { author, content } = req.body;
  if (!author || !content) {
    return res.status(400).json({ success: false, error: 'Cần author và content' });
  }

  const comment = {
    id: nextCommentId++,
    postId: id,
    author: author.trim(),
    content: content.trim(),
    createdAt: new Date().toISOString()
  };
  comments.push(comment);
  res.status(201).json({ success: true, data: comment });
});

Dễ

8.1 Thêm route tìm kiếm

Thêm route GET /api/posts/search?q=keyword vào Blog API trên để tìm kiếm bài viết theo title. So sánh không phân biệt chữ hoa/thường. Nếu không có kết quả, trả về array rỗng (không phải 404). Nếu thiếu param q, trả về 400 Bad Request.

Trung bình

8.2 Route thống kê blog

Implement GET /api/stats trả về object chứa: totalPosts, totalComments, postWithMostComments (object đầy đủ + commentCount), topAuthors (array 3 author có nhiều bài nhất), popularTags (5 tags xuất hiện nhiều nhất). Gợi ý: dùng Array.reduce() để đếm.

Khó

8.3 Pagination thực sự

Implement pagination hoàn chỉnh cho GET /api/posts. Query params: ?page=1&limit=10. Response phải có: { data, total, page, limit, totalPages, hasNext, hasPrev }. Thêm validation: page phải >= 1, limit phải trong [1, 100], nếu page vượt quá totalPages thì trả về data rỗng nhưng vẫn có thông tin pagination đúng.
