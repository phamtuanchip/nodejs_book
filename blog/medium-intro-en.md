# Learn Node.js From the Ground Up: A Free Vietnamese Book for JavaScript Developers

*18 chapters from "how does the web work?" to Express, databases, testing, deployment and serverless.*

If you know basic JavaScript but have never written a server, Node.js can feel like a pile of unrelated tools. This book starts with how the internet works, then builds up to a production-style backend, one layer at a time. **It is written in Vietnamese today; an English edition is planned.**

## Who it is for

- Developers who know JavaScript (ES6+) but nothing about server-side programming
- Readers who want to become backend or full-stack developers
- No prior knowledge of HTTP, APIs or databases is needed

## What is inside

- **Part 1 — Foundations:** how the web works (HTTP, DNS, client and server), stateless vs stateful applications, what Node.js is and how to set it up
- **Part 2 — Node.js basics:** core modules, asynchronous programming, a plain HTTP server, the npm ecosystem
- **Part 3 — Web applications with Express:** routing, middleware and error handling, cookies, sessions and authentication, templating and server-side rendering
- **Part 4 — Data:** MongoDB with Mongoose, PostgreSQL with Prisma, caching with Redis
- **Part 5 — Advanced and cloud:** REST API design, testing and code quality, deployment and DevOps basics, serverless and cloud functions

Every chapter has a goal, explanations, sample code in the `examples/` folder, and an exercise. The book is read in the browser, with PDF and EPUB versions also available.
